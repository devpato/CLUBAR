# CLUBAR Consulting

Website for CLUBAR Consulting: marketing, trade marketing and operations for clubs, bars and restaurants. New York, Mexico City and Madrid.

A single static page (`index.html`) with English and Spanish versions. No build step: open it in a browser or serve the folder with any static host (GitHub Pages, Netlify, Vercel).

## Before going live

- Replace the placeholder contact email `hello@clubarconsulting.com` in `index.html` (search for `CONTACT_EMAIL`).
